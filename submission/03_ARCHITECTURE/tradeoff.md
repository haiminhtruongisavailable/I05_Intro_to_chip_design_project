# Tradeoff

A table or a wide multiplier spends area on one sample. This core spends clocks: one load, eight iterations, and one sample.

`x` and `y` are 16 bits so that \(K = 9949\) fits. The flip-flop count is 66. The charter hint of about 27 to 30 assumes 8-bit `x`, `y`, and `z`.

No second netlist that contains a multiplier was synthesized. This hand-in has no percentage of area saved.
